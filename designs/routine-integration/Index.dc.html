Smart Briefings — setup, status & revoke

A family owner uses their existing Claude or ChatGPT subscription to run a provider-owned routine that drafts Dayfold updates. The provider owns the schedule, usage, and Google connections; Dayfold owns a revocable, hub-scoped grant, review controls and run receipts. Setup is an honest two-surface ceremony — “You'll finish setup in {provider}” — and activation is proven only by the first idempotent dayfold_run_finish receipt. Every failure below derives from a closed phase/reason contract, never raw provider errors. Default-off · review-first · least privilege · reversible.
